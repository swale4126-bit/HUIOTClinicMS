## HUIOT Clinic Management System (HUIOT Clinic MS)

**ASP.NET Core | C# | Entity Framework Core | SQL Server | Bootstrap | Full-Stack**

Developed a full-stack, queue-based **Clinic Management System** to digitize and streamline clinical workflows from patient registration through treatment and medication dispensing. The system provides role-based modules for healthcare staff and manages the complete patient-care workflow, including:

- Patient registration and queue-based patient management
- Medical record creation and consultation workflow
- Laboratory test requests and laboratory result processing
- Nurse-managed prescription creation based on completed laboratory results
- Pharmacist medication dispensing and medication records
- Role-based access control for Health Officers, Nurses, Laboratory Technologists, Pharmacy Officers.
- Relational database design and data management using **Entity Framework Core and SQL Server**
- Responsive dashboards and role-specific interfaces using **ASP.NET Core MVC and Bootstrap**

The project demonstrates full-stack application development, database-driven workflow design, authentication and authorization, and integration of multiple healthcare modules into a unified clinical information management system.
